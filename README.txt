Digonto QR 1.0
==============
Make QR codes for a link, text, Wi-Fi, contact card, e-mail, phone, SMS, WhatsApp or a map location.

Style: dots (square, rounded, dots, diamond, liquid, leaf, bars), corner eyes (frame and center shapes, own colors),
one color or gradient, transparent or solid background, a logo in the middle (the correction level is raised
automatically so the code still scans), and a frame with a text label.
Export: PNG (any size), SVG and PDF (sharp for print). "Many codes from a list" makes a whole folder at once,
for example one code per table. File > Save project keeps everything as a .dqr file (older .pqr files still open) you can reopen.

Always test a code with your phone before printing it. Dark code on a light background scans best.
The QR encoder is part of this program (standard QR, ISO 18004) - no QR library is downloaded.
Only PySide6-Essentials is installed, locked with SHA-256 hashes.
